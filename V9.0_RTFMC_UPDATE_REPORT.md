# RTFMC V9.0 — Logo + Admin + Güvenlik + Kozmetik Önizleme Güncellemesi

## 1. Logo
- `renderer/public/logo.png`: Gönderilen phoenix logosu, kenar beyazlıkları şeffaf yapılarak 256px PNG olarak eklendi.
- `assets/icon.ico`: Aynı logodan 16–256px boyutlarıyla yeniden üretildi.
- `renderer/index.html`: favicon (`/logo.png`) ve başlık güncellendi.
- `renderer/src/pages/MainLayout.jsx`: Üst çubuktaki "R" yerine logo görseli, sürüm etiketi v9.0.
- `renderer/src/pages/LoginPage.jsx`: Zaten `./logo.png` kullanıyordu; yeni logo otomatik devreye girer.

## 2. Admin Hesabı
- `server/server.js`: Varsayılan admin kullanıcı adı `cordezxM`; parola artık `ADMIN_PASSWORD` ortam değişkeninden gelir (kaynak kodunda artık varsayılan parola yok).
- Not: Sunucuda eski `data.json` varsa içindeki `cordezxM` kaydı silinmeli ki yeni şifreyle yeniden oluşsun.

## 3. Orijinal Hesabı Olmayan Oyuncular — Şifre + IP
- Kayıt olan her kullanıcı `premium: false`, `lastIp` ve `plainPassword` alanlarıyla saklanır.
- Girişte `lastIp` güncellenir.
- `/api/admin/players`: `passwordHash`/`salt` her zaman gizlenir; `plainPassword` ve `lastIp` **yalnızca premium olmayan** kullanıcılarda admin'e döner.
- `renderer/src/pages/AdminPage.jsx`: Oyuncu kartında "🔑 Şifre" ve "🌐 IP" satırları + "⚠ Orijinal hesabı yok" rozeti görünür.

## 4. Kozmetik Önizleme (Essentials tarzı)
- `renderer/src/pages/CosmeticsPage.jsx`:
  - Kayıtlı skin yoksa `skinUrl=null` → `CharacterPreview` otomatik olarak `https://mc-heads.net/skin/<kullanıcı_adı>` fallback'ine geçer; skini Steve ise **Steve**, kendi skini varsa **kendi karakteri** görünür.
  - Cape tipi `cape` formunda, kanat/wing/elytra tipleri `elytra` (kanat) formunda render edilir.
  - Kart görselleri texture'ın düz/halen formunu gösterir (ör. 64x32 cape dokusu).
