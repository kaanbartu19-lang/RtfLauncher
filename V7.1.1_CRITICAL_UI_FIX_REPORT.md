# RtfLauncher V7.1.1 — Critical Profile UI / Skin Fix

## Exact scope
- No navigation rewrite.
- No Minecraft launch rewrite.
- No Modrinth API redesign.
- No dependency version changes.

## Profile page
- Two-column instance workspace with a dedicated right-side profile rail.
- Existing/legacy profile data is recovered when `modProfiles` is missing or empty.
- Profile header actions are pinned to the top-right of the header: Play, Settings, More.
- Play icon uses a CSS triangle to avoid font baseline drift.
- Header reserves action space so long profile names cannot push buttons out of alignment.
- Desktop and responsive rules are separated.

## Browse Content
- Existing profile content browser retained.
- Mods / Resource Packs / Data Packs / Shaders remain profile-scoped.
- Existing install/installed state remains untouched.

## Skin
- Renderer sends the skin bytes as a plain ArrayBuffer clone over Electron IPC.
- Main process accepts Buffer, ArrayBuffer and typed-array views.

## Validation
- Static QA executed after changes.
- Real Windows runtime is still required for final PASS.
