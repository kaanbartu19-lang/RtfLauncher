# RtfLauncher V8.0 — Profile & Content System Rebuild

## KÖK SEBEPLER ("Profil bulunamadı")
1. `LoginPage.handleMicrosoft` → `saveConfig({ user })` tüm config.json'u sadece `{user}` ile değiştiriyordu → tüm profiller siliniyordu (ve Microsoft token'ı düz metin olarak yazılıyordu).
2. `App.jsx` giriş/çıkışta başlangıçta okunan eski config kopyasını geri yazıyordu → sonradan oluşturulan profiller kayboluyordu.
3. 4+ bileşen aynı config.json'u read-modify-write ediyordu (yarış durumu).
4. `normalizeProfiles`: son profil silinince eski `profiles` listesi geri diriliyordu.
5. Play, global `.minecraft/mods` içinden jar'ları profile kopyalıyordu (profil kirlenmesi).
6. MCLC 3.18 `server:` seçeneğini desteklemiyor → otomatik sunucuya bağlanma sessizce çalışmıyordu (artık `quickPlay`).
7. İndirmelerde HTTP durumu/hash kontrolü yoktu; 404 sayfası `.jar` olarak kaydedilebiliyordu, yarım dosya tekrar denemeyi engelliyordu.
8. Admin/kozmetik: backend token hiç kaydedilmiyordu → her admin isteği 401 → yanlış "admin hesabıyla giriş yap" mesajı; sunucu 403 yerine 401 dönüyordu.
